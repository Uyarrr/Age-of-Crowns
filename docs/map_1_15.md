# Victoria 3 1.15 map compatibility

Checked against the installed **1.15.0 (Ivan-Chai)** map. Age of Crowns inherits
vanilla map geometry but replaces starting state ownership. The update moved
existing province IDs between states, so the old ownership history left gaps
and referenced states that no longer exist.

| Retired state | Successor |
| --- | --- |
| Kaunas | Lithuania |
| Tartaria | Saratov |
| Chukotka | Kamchatka |
| Galich | Mainly Vologda; also Kostroma, Vyatka and Yaroslavl |

The repair moves **897 province assignments** into their current state regions,
keeping their existing 1444 owners. It covers the Russian boundary changes,
Moravia/Upper Silesia/West Galicia, and the Sakhalin and Ryukyu island changes.
The missing West Micronesian province `xEF50C0` joins `OPD`, the mod's existing
regional Pacific owner.

It also resolves **119 overlapping assignments**. Dedicated La Plata history
supersedes stale converter history in Buenos Aires and Los Rios. Explicit
Mapuche territory takes precedence over the broad Tehuelche list in Patagonia;
the explicit `TBI` enclave takes precedence over the broad Amazonian list in
Para. Ryukyu retains its island rather than the obsolete Formosan assignment.
All **40,598 previously uncontested province owners** were independently checked
against the original Git files and remain the same.

Population follows each old owner's territory into successor states using
province-count proportions and integer remainder allocation. This preserves
every culture/religion/pop-type total. Three orphan population scopes can be
recovered from the archived converter province lists. Two others (`N01` in Para
and `N10` in Patagonia) have no surviving province list and are divided between
their original state's intended owners. These are geographic estimates, not
new historical population research. The exact decisions are recorded in
`map_1_15_migration.json`.

Buildings move intact to their owner's largest successor region. The migration
preserves all **312,807,718 people** and **915 starting building blocks** globally.
Custom resource amounts are split proportionally or combined in merged states;
agricultural potential follows the successor regions. Capitals and formation
and release rules use current state names, with merged states listed once.

Run from the mod root:

```powershell
node tools/audit_map_ownership.cjs
node tools/audit_map_1_15.cjs
```

The first command compares ownership with the installed map and detects future
map changes. Set `VICTORIA3_GAME_DIR` to another installation's `game` folder if
needed. The second checks the reviewed ownership manifest, population and
building conservation, migrated history scopes, resources, migrated capitals,
and retired state references. `migrate_map_1_15.cjs` documents the one-time
migration and refuses to run again after its manifest exists.

These checks validate the files; an in-game load has not been performed.
Start a **new campaign** to test the revised starting history. Existing saves
store their own ownership and population and will not receive this migration.
